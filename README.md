# 课堂点名 · Class Check-in

给大学班级用的点名工具：**班长安卓 App 亮二维码 → 同学扫码打一个名字 → 云端实时算「已到 x/60」→ 结束点名出四类名单，可导出 Excel**。

设计目标：**同学端零学习成本**（微信/相机扫码，只打自己的名字），所有复杂度压在班长端和服务端。

---

## 特性

**同学端（网页，扫码即用，不用装任何东西）**
- 只接受中文姓名（2–10 个汉字或含「·」），其他字符打不进去
- 首次使用先阅读并同意《隐私说明》才能签到
- 提交结果实时反馈：「签到成功，你是第 N 位」

**班长端（安卓 APK，侧载）**
- 房间号 + PIN 登录，**没有账号体系**（不注册、不绑手机、不用微信授权）
- 导入花名册 Excel/CSV，全屏二维码 + 大计数 + 每来一人轻震动
- 结束点名 → 已到 / 未到 / 请假 / 异常四类名单，一键导出 Excel/CSV（含留证列）
- 历史记录 + 「复制上次请假名单」

**反作弊（两层设计，边界写在文档里，不吹）**
- **硬拦**：中文名校验、**姓名必须在本班名单里**（只上传姓名哈希，服务端看不到明文姓名）、
  **一台设备一节课只能签一个名字**（清缓存换身份也会被认出）、关闭后拒收
- **标黄留证**：未提供定位、距离偏离、坐标抄袭（两台设备报同一组精确坐标）、定位精度异常、
  设备特征完全相同（属性指纹）、IP 与定位不符、疑似机房/代理出口、同名重复
- 每次被挡下来的提交也会留证，导出时单独一张「被挡记录」表

**明确做不到的（浏览器层面没有接口）**：拿不到手机序列号、拿不到「是否模拟定位」标志位、
不能强制 WiFi 定位、无法检测 root、「换一台手机来替签」只能靠随堂抽查 + 留证追责。

## 架构

```
班长端 APK（WebView 外壳）
  └─ 加载云端页面 → 建班 / 导入花名册 / 发起点名 / 亮二维码 / 看名单 / 导出
                        │  HTTPS + JSON API
同学端网页（同一个页面的另一种模式：?s=场次码）
  └─ 填姓名 → POST /api/checkin
                        │
服务端（Node，零依赖，单端口）
  ├─ 静态托管（页面 + 自带的二维码/表格库，不依赖外部 CDN）
  ├─ 场次与提交存储（落盘 JSON，默认 ~/.classcheckin）
  └─ 全部判定都在服务端：名单校验、设备限制、冷却、坐标/IP/指纹标黄
```

**关键设计选择**
- **花名册不上传**：只上传「姓名哈希 + 随机盐」，服务端能判断"在不在名单"，但看不到任何姓名；
  比对出勤也在班长手机本地完成。
- **设备身份三处冗余**（cookie + localStorage + sessionStorage）+ 属性指纹（屏幕/字体/显卡渲染特征），
  前者用于硬拦，后者用于标黄（同款机型属性相同，不能用来硬拦）。
- **零依赖后端**：只用 Node 内置模块，`npm start` 即可跑，方便部署到任何单端口环境。

## 快速开始

### 1. 部署你自己的云端

```bash
cd app
npm start            # 监听 $PORT（默认 3000）
```

任何能跑单端口 HTTP 服务的环境都行。数据默认写在 `~/.classcheckin`，可用 `CHECKIN_DATA_DIR` 指定。

### 2. 打包班长端 APK

```bash
cd android
# gradle.properties 里把 siteHost 改成你的部署域名（不含 https://）
gradle assembleRelease
```

签名密钥自己生成（`keytool -genkeypair ...`，见 `docs/使用说明.md`），
`keystore.properties` 不存在时会自动回退用 debug 签名（能装，但不能升级到正式包）。

### 3. 网页端配置

`app/config.js`：

```js
window.APP_CONFIG = {
  siteOrigin: '',          // 留空 = 自动用当前页面地址（换域名不用改代码）
  operator: '本班班长'      // 《隐私说明》里"数据管理者"的称呼
};
```

## ⚠️ 已知平台限制：微信内置浏览器

**多数托管平台的发布域名会拦截微信内置浏览器**（返回平台自己的页面「当前应用不支持在微信内打开」）。
这不是代码问题。实测：iPhone Safari / 安卓 Chrome / 小米 / 华为 / QQ 浏览器全部正常，**只有微信内置浏览器被拦**。

因此推荐用法：**同学用手机相机扫码**（或用聊天里的链接在浏览器打开并收藏，之后每节课输屏幕上的 6 位口令）。

## 目录结构

```
app/                 同学端 + 班长端网页 + Node 服务端
  ├─ index.html      两个模式：?s=场次码 → 同学签到；否则 → 班长端
  ├─ app.js          全部前端逻辑（含设备指纹、名单哈希、导出）
  ├─ server.js       零依赖服务端（静态托管 + 点名 API）
  ├─ privacy.html    《隐私说明》
  └─ libs/           自带的二维码 / 表格库（不依赖外部 CDN，国内网络更稳）
android/             班长端 APK 工程（Java + WebView 外壳 + 原生桥）
docs/                使用说明、花名册导入模板
```

## 隐私

见 `app/privacy.html`（应用内也有入口）。要点：不收集剪贴板/通讯录/相册/短信/序列号/手机号；
唯一第三方是 `ipwho.is`（只发 IP，用于判断机房/代理出口，可用环境变量 `CHECKIN_IP_LOOKUP=0` 关闭）。
