# 课堂点名 App · 使用说明

一个给大学班级用的点名工具：班长安卓手机亮二维码 → 同学扫码打名字 → 云端算「已到 x/60」→ 结束点名出已到/未到/请假/异常四类名单，可导出 Excel。

## 一、它由两部分组成

| 部分 | 说明 |
|---|---|
| **同学端**（网页） | 相机扫码打开，只填一个姓名（中文，2–15 字） |
| **班长端**（安卓 APK） | 建班、导花名册、发起点名、亮二维码、看名单、导出记录 |

**部署自己的云端**：把 `app/` 整个目录用任意支持 Node 的环境跑起来（`npm start`，监听 `PORT`）。

> ⚠️ **必须 HTTPS**：浏览器只在安全上下文（HTTPS / localhost）提供定位与加密哈希。用 HTTP 部署会导致定位全部失效、哈希退化，而且**没有任何报错提示**。

## 二、装机（只在班长手机上装 APK）

1. 把 APK 发到手机安装（系统提示「未知来源应用」→ 允许）。
2. **不需要任何账号**：首次打开只要房间号 + 自定的 PIN。

**自己打包 APK**（源码在 `android/`）：

```bash
# 1) 改域名：android/gradle.properties 里的 siteHost 换成你的部署域名（不含 https://）
#    仍留着占位符 your-domain.example.com 的话，构建会直接失败并提示
# 2) 生成你自己的签名密钥（升级必须沿用同一个）
keytool -genkeypair -v -keystore keystore/myapp.jks -alias myapp \
  -keyalg RSA -keysize 2048 -validity 10950 -storetype PKCS12 \
  -storepass 你的口令 -keypass 你的口令 -dname "CN=YourName, O=YourOrg, C=CN"
# 3) 在 android/keystore.properties 里写：
#    storeFile=keystore/myapp.jks / storePassword=... / keyAlias=myapp / keyPassword=...
# 4) 打包
cd android && gradle assembleRelease
# 没有 keystore.properties 时会自动用 debug 签名（也能装，但不能升级到正式包）
```

## 三、关于 PIN 的实话（别当成账号体系）

PIN 是两道东西的合体：**① 班长手机上的本地锁**（防止同学随手点开 App 看到记录）；**② 与服务端约定的房间口令**。

它**不是身份认证**——知道口令的人直接调接口就能读写该房间数据。所以：
- 口令和二维码一样是入场券，**不能外传**；
- 服务端所有房间级接口都以口令为唯一凭据；
- 真要更强的隔离需要账号体系或设备绑定，那是另一个项目。

## 四、首次设置（班长端，3 分钟）

1. 阅读并勾选同意《隐私说明》→ 填班级名、房间号（自定义）、PIN（4–6 位数字）
2. 按需决定是否勾选「**启用 IP 归属地校验**」（判断境外/机房代刷；开启后服务端会把学生 IP 发给第三方 `ipwho.is` 查询，**可以关掉**）
3. 导入花名册：把 `docs/花名册导入模板.xlsx` 填好（第一行要有「姓名」列，学号列可选）
4. 核对人数；转走的同学点「停用」，历史记录不受影响

## 五、每节课怎么用

1. 首页填课程名（可留空）→ 点「开始点名」（首次会问定位权限）
2. 把二维码**投到教室投影**或举在讲台，同学扫码（**用手机相机扫，别用微信扫一扫**，见下）→ 打自己名字
3. 屏幕上是「已到 x/60」大计数，每来一个人轻震一下
4. 点「结束点名」→ 二维码立即失效
5. 看四类名单：已到 / 未到 / 请假 / 异常；未到的人点「请假」即可归到请假档
6. 导出 Excel 或 CSV（含提交时间、距离、IP 归属、设备标识、标记等留证列 + 一张「被挡记录」表）

**点名中出现「有 N 台设备提交被挡下」**：说明有人用同一部手机替别人签。卡片按设备归并（一台一行，显示共几次、试过哪些名字），确认是"两人共用一部手机"就点那行的「**放行**」让对方重试一次；代刷则不用管，已留证。

**改过花名册**：点名界面点「重新同步名单」，否则新加的同学会被名单校验拒收。

## 六、异常栏怎么读

| 标记 | 含义 | 怎么处理 |
|---|---|---|
| **未提供定位** | 这节课有教室坐标，但这条没给定位 | 关掉定位权限并不能隐身 |
| **距离偏离** | 提交时人不在教室半径内（默认 200 米） | 结合座位核对 |
| **与他人坐标完全相同** | 两台不同设备报上米级完全一致的坐标 | 高度可疑 |
| **定位精度异常** | 上报精度为 0 或离谱值 | 模拟定位的常见特征 |
| **设备特征与他人完全相同** | 屏幕/字体/渲染特征一模一样 | 可能是清缓存换身份，也可能是**同款手机**，需结合判断 |
| **IP 与定位不符** | 定位在国内、出口 IP 在境外 | 多半挂了代理/加速器（IP 可被伪造，这只是参考证据） |
| **疑似代理/VPN** | 出口 IP 属于机房/云厂商 | 参考，也可能是游戏加速器 |
| **同名重复** | 同一个名字被两台设备提交 | 问本人 |

## 七、反作弊：能做到的 / 做不到的

**硬拦（真的不让提交）**
- 姓名必须是 2–15 个汉字（覆盖扩展区生僻字），**且必须在本班花名册里**——班长端只上传**姓名哈希 + 随机盐**，服务端看不到任何姓名明文
- **同一台设备一节课只能签一个名字**；清缓存/换隐身模式换身份也会被认出来（身份同时存 cookie、localStorage、sessionStorage 三处）
- **「放行」= 班长手动豁免一次**（两人共用一部手机时用）
- 点名关闭后一律拒收

**标黄 + 留证（不拦）**：上面异常栏里除硬拦以外的项；每次被挡下来的提交也会留证。

**做不到（浏览器层面没有接口）**：拿不到手机序列号、拿不到「是否模拟定位」标志位、不能强制 WiFi 定位、无法检测 root、「换一台手机来替签」只能靠随堂抬头抽查 + 留证追责。

## 八、隐私

同学**首次签到前必须先阅读并同意**《隐私说明》（应用内 `/privacy`），班长端建班也要勾选；条款更新会要求重新确认。

- **会记录**：姓名、提交时间、设备标识与设备特征、IP、定位（**仅当允许**）、姓名哈希（核对名单用，不含明文）
- **不收集**：剪贴板内容、通讯录、相册、短信、通话记录、手机序列号、IMEI、手机号、微信号
- **保存多久**：本机与云端都只保留**最近 60 场**，超出自动淘汰；要长期保存请导出
- **删除**：历史页可删单条 / 清空全部；同学想删自己某条记录，直接找班长
- **第三方**：仅 `ipwho.is`（只发 IP，可在建班时勾掉，或设 `CHECKIN_IP_LOOKUP=0`）

## 九、常见问题

- **同学说打不出自己的名字**：姓名支持全部汉字（含生僻字，如「𠀀」），最长 15 字；如果还打不出，说明这个名字不在花名册里，找班长核对
- **打开是白屏**：教室信号差时首屏需要一两秒（已按需加载大库，实测弱网 2.4 秒），不行就把 App 从后台划掉重开
- **导出的文件在哪**：手机「文件管理 → 下载」，文件名形如 `高等数学_20261014-0900.xlsx`
- **怎么换班级 / 换 PIN**：解锁页底部「忘记口令 / 重设班级」
- **历史记录**：结果页上方「历史记录」，本机记录 + 云端存档都会列出（各保留最近 60 场）
- **提示"这个名字不在班级名单里"**：核对花名册有没有错别字；刚加过人就点「重新同步名单」
